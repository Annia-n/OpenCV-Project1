# OpenCV Project 1

**Overview:**  
This repository contains a collection of simple Python scripts demonstrating basic image processing operations using the OpenCV library.

## Project Structure
- **show_image.py** – Displays an image (e.g., `fruit.webp`).  
- **Gray-image.py** – Converts an image to grayscale.  
- **ROI.py** – Selects and displays a specific Region of Interest (ROI) from the image.  
- **Bluring.py** – Applies a blurring effect to the image.  
- **fruit.webp** – Sample image used in the scripts.

## Requirements
- Python 3.x  
- OpenCV library (install via pip):

  pip install opencv-python
